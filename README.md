# M3AK AI — معاك 🇲🇦

**معاك، خطوة بخطوة.**

رفيق ذكي مغربي: دعم عاطفي غير علاجي (فضفض معايا)، مساعد يومي (سول معاك)، تحليل وحل المشاكل (حل مشكلتي)، تنظيم اليوم (نظم نهاري)، ومتابعة الأهداف والعادات (تقدم ديالي). يتحدث الدارجة المغربية ويفهم العربية والفرنسية والدارجة بالحروف اللاتينية.

## التقنيات

- تطبيق ويب تقدمي **PWA** — HTML/CSS/JavaScript نقي، بلا أطر عمل وبلا تكلفة استضافة.
- تخزين محلي فقط (localStorage) — لا خادم، لا حسابات في النسخة الأولى، لا تتبع.
- صوت مجاني عبر Web Speech API (إدخال صوتي + قراءة الردود) — يعمل في Chrome.
- قابل للتثبيت على الهاتف (manifest + service worker + عمل دون اتصال للمحتوى الأساسي).

## التشغيل محلياً

```bash
cd m3ak-ai
python3 -m http.server 8901
# افتح http://127.0.0.1:8901
```

## النشر (GitHub Pages — مجاني)

1. ارفع ملفات المشروع إلى مستودع GitHub.
2. من إعدادات المستودع: **Settings → Pages → Source: main / (root)**.
3. الرابط يكون: `https://<username>.github.io/<repo>/`

## ما الذي يعمل فعلياً في هذه النسخة؟

- ✅ التنقل الكامل بين 7 أقسام، وضع فاتح/داكن، عربية (RTL) وفرنسية (LTR) لواجهة التطبيق.
- ✅ إدارة مهام كاملة (إضافة/تعديل/حذف/إكمال، أولويات، تواريخ، عرض اليوم/الأسبوع/الكل، اقتراح خطة يوم، مراجعة نهاية النهار).
- ✅ أهداف مع مؤشر تقدم، وعادات يومية مع سلسلة أيام (streak)، وملخص أسبوعي.
- ✅ محادثة بثلاثة أوضاع بشخصية دارجة دافئة، فهم سياقي أساسي، كشف حالات الخطر والتوجيه لخدمات الطوارئ المغربية (15/19).
- ✅ وضع «حل مشكلتي» موجّه: وصف → سؤال توضيحي → خيارات → خطة → زر «حوّل الحل إلى خطة» يضيف الخطوات كمهام.
- ✅ ذاكرة اختيارية (الاسم/اللغة/الأهداف) قابلة للعرض والحذف؛ محادثات الفضفضة لا تُحفظ تلقائياً أبداً.
- ✅ إدخال صوتي وقراءة صوتية للردود (حسب دعم المتصفح).
- ✅ تصدير البيانات JSON ومسح شامل للبيانات.

## الذكاء الاصطناعي: الوضع التجريبي والربط الحقيقي

- افتراضياً يعمل التطبيق **بوضع تجريبي محلي واضح التسمية**: محرك ردود مبرمج بعناية على الشخصية المغربية — ليس نموذج ذكاء اصطناعي حقيقياً، ولا يدّعي ذلك.
- الذكاء الحقيقي مفعّل افتراضياً عبر **Pollinations** (مزود مجاني متوافق مع OpenAI API، بلا حساب وبلا مفتاح — Endpoint: `https://text.pollinations.ai/openai`، الموديل `openai`). حدود الرتبة المجانية المجهولة تجعله مناسباً للنسخة الأولى. (بقرار من المالك في 2026-10-22: لا تظهر أي إعدادات تقنية للمستخدمين — لا حقول رابط/موديل/مفتاح في الواجهة؛ الإعدادات → الذكاء الاصطناعي فيها فقط حالة التفعيل ومفتاحا الموافقة/التفعيل، والربط مدمج في الكود.) (ملاحظة: محاولة ربط Groq بحساب المالك في 2026-10-22 اصطدمت بجدران تسجيل دخول Google/GitHub/روابط بريدية مستهلَكة، فتم اختيار المزود الخالي من الحساب.)
- **للإنتاج العام**: لا توزع مفتاحاً داخل التطبيق. الخطوة التالية المخططة هي خادم وسيط (serverless مجاني) يحمل المفتاح ويطبق حدود الاستخدام، مع تعليمات النظام (System Prompt) الموجودة في `app.js` (`SYSTEM_PROMPT`).

## الخصوصية والسلامة

- البيانات لا تغادر جهاز المستخدم إلا إذا فعّل بنفسه ربط ذكاء خارجي ووافق صراحة.
- التطبيق ليس خدمة طبية أو علاجاً نفسياً — توجد إخلاءات مسؤولية وتوجيهات أزمات داخل الواجهة.
- مصمم باحترام مبادئ القانون المغربي 09-08 لحماية المعطيات الشخصية.

## خارطة الطريق

- خادم وسيط آمن للذكاء الاصطناعي + حسابات ومزامنة اختيارية.
- M3AK Plus: حدود استخدام أوسع وأدوات تنظيم متقدمة.
- M3AK Business: إنتاجية للفرق دون أي وصول لمحادثات الموظفين الشخصية.
- تحسين فهم الدارجة الصوتي (نماذج مغربية متخصصة عند توفرها مجاناً).

## البنية

| الملف | الدور |
|---|---|
| `index.html` | جميع الأقسام والواجهات |
| `styles.css` | الهوية البصرية (أخضر زمردي + عنبري، فاتح/داكن) |
| `app.js` | التخزين، محرك المحادثة وشخصيته، المهام/الأهداف/العادات، الصوت، الربط بالذكاء |
| `manifest.webmanifest` + `sw.js` + `icon.svg` | قابلية التثبيت والعمل دون اتصال |
