# Work 🎯

**ما تفوتك حتى فرصة.**

تطبيق ويب تقدمي (PWA) كيجمع مباريات التوظيف في **القطاع العمومي المغربي** من بوابة التشغيل العمومي (emploi-public.ma) ومواقع الجهات المنظمة، وكيعرضها بالدارجة المغربية:

- 🎯 قائمة المباريات المفتوحة مرتبة حسب آخر أجل، مع عدّاد تنازلي ملوّن حسب القرب
- 📄 صفحة تفاصيل لكل مباراة: الشروط، الدبلوم، المناصب، وطريقة الترشيح
- 🗂️ لائحة وثائق تفاعلية — علّم على اللي وجدتي وتابع التقدم
- ✅ «واش مؤهل؟» — فاحص أهلية بالعمر والديبلوم
- ⭐ «مبارياتي» — تتبع مبارياتك مع تنبيهات الأجل داخل التطبيق
- 📅 إضافة الأجل إلى تقويم Google، ومشاركة عبر واتساب
- 👤 حساب اختياري (Firebase) لمزامنة التتبع بين الأجهزة

البيانات في `concours.json` تُراجع يومياً مقابل الإعلانات الرسمية؛ كل مباراة عندها رابط الإعلان الرسمي. **المرجع النهائي دائماً هو الإعلان الرسمي، والتسجيل يتم عند الجهة المنظمة.**
